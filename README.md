Aerthwaite — a travel poster for a floating lantern archipelago that isn't there: sky-islands chained by rope bridges, paper lanterns glowing warm gold against deep teal dusk, and one tall lighthouse-island guiding travellers home. Drawn procedurally in pure Python (stdlib only) by `main.py` — no network, no external assets.

## Run it

```sh
python3 main.py
```
